PART 1: BASIC CONCEPTS - WHAT ARE VARIABLES?
======================================================================================================================================================

1. CONCEPT: VARIABLES
-----------------------------------------------------------------------------------------------------------------------------------------------------
Variables are containers for storing data values.
In Java, variables store information that can be used and changed throughout your program.

Think of a variable like a labeled box:
- The box holds a value (data)
- The label has a name (variable name)
- You can put different things in the box (assign values)


2. DATA TYPES IN JAVA
-----------------------------------------------------------------------------------------------------------------------------------------------------
Java has different types of variables to store different types of data:

📌 String
  - Stores text (sequence of characters)
  - Values surrounded by double quotes ("")
  - Example: String name = "Hello";

📌 int
  - Stores integers (whole numbers, no decimals)
  - Can be positive or negative
  - Example: int age = 25;

📌 float
  - Stores floating-point numbers (decimals)
  - Must end with 'f' suffix
  - Example: float price = 19.99f;

📌 char
  - Stores single characters only
  - Values surrounded by single quotes ('')
  - Example: char letter = 'A';

📌 boolean
  - Stores true or false values
  - Used for logical conditions
  - Example: boolean isStudent = true;

Example of Different Data Types:
---
int myNum = 5;
float myFloatNum = 5.99f;
char myLetter = 'D';
boolean myBool = true;
String myText = "Hello";


PART 2: DECLARING (CREATING) VARIABLES
======================================================================================================================================================

3. HOW TO DECLARE A VARIABLE
-----------------------------------------------------------------------------------------------------------------------------------------------------
To create a variable in Java, follow these steps:

Step 1: Choose a data type (like int, String, float, etc.)
Step 2: Give the variable a name (identifier)
Step 3: Optionally assign it a value using =

SYNTAX:
type variableName = value;


4. VARIABLE DECLARATION EXAMPLES
-----------------------------------------------------------------------------------------------------------------------------------------------------

Example 1: Declaring a String variable
---
String name = "John";
System.out.println(name);  // Output: John

Breakdown:
- String = data type
- name = variable name
- "John" = the value assigned


Example 2: Declaring an int variable
---
int myNum = 15;
System.out.println(myNum);  // Output: 15


Example 3: Declaring without initial value
---
int myNum;           // Variable declared
myNum = 15;          // Value assigned later
System.out.println(myNum);  // Output: 15

Note: You can declare a variable without assigning a value immediately, but you must assign a value before using it.


Example 4: Reassigning a variable
---
int myNum = 15;
myNum = 20;          // Value changed from 15 to 20
System.out.println(myNum);  // Output: 20

Important: When you assign a new value to a variable, it overwrites the previous value.


PART 3: DISPLAYING VARIABLES & TEXT CONCATENATION
======================================================================================================================================================

5. PRINTING VARIABLES
-----------------------------------------------------------------------------------------------------------------------------------------------------
Use System.out.println() to display variables in the console.

Example 1: Print a single variable
---
String name = "John";
System.out.println(name);  // Output: John


Example 2: Combine text and variable
---
String name = "John";
System.out.println("Hello " + name);  // Output: Hello John

The '+' symbol is used to concatenate (join) text and variables.


Example 3: Combine multiple variables
---
String firstName = "John ";
String lastName = "Doe";
String fullName = firstName + lastName;
System.out.println(fullName);  // Output: John Doe


6. THE + OPERATOR (Two Different Meanings)
-----------------------------------------------------------------------------------------------------------------------------------------------------
In Java, the '+' symbol has TWO different behaviors depending on context:

📌 For STRINGS (Text):
  '+' CONCATENATES (joins) strings together
  
  Example:
  String a = "Hello";
  String b = "World";
  System.out.println(a + b);  // Output: HelloWorld

📌 For NUMBERS:
  '+' ADDS values mathematically
  
  Example:
  int x = 5;
  int y = 6;
  System.out.println(x + y);  // Output: 11


7. MIXING TEXT AND NUMBERS - IMPORTANT!
-----------------------------------------------------------------------------------------------------------------------------------------------------
⚠️ BE CAREFUL when combining text and numbers in one line!

❌ WITHOUT PARENTHESES (Treats numbers as text):
---
int x = 5;
int y = 6;
System.out.println("The sum is " + x + y);  // Output: The sum is 56

Why? Because:
1. "The sum is " is a String
2. When you add x (5), it becomes "The sum is 5" (concatenation)
3. When you add y (6), it becomes "The sum is 56" (concatenation)
4. Result: "The sum is 56" (NOT 11)


✅ WITH PARENTHESES (Calculates numbers first):
---
int x = 5;
int y = 6;
System.out.println("The sum is " + (x + y));  // Output: The sum is 11

Why? Because:
1. (x + y) is calculated first → 5 + 6 = 11 (math)
2. Then "The sum is " + 11 → "The sum is 11" (concatenation)
3. Result: "The sum is 11" (CORRECT!)

🎯 KEY LESSON: Use parentheses when you want to do math BEFORE concatenating with text!


PART 4: DECLARING MULTIPLE VARIABLES
======================================================================================================================================================

8. MULTIPLE VARIABLES OF THE SAME TYPE
-----------------------------------------------------------------------------------------------------------------------------------------------------
You can declare more than one variable of the same type in a single line using commas.

❌ LONGER WAY:
---
int x = 5;
int y = 6;
int z = 50;
System.out.println(x + y + z);  // Output: 61


✅ SHORTER WAY (Same result):
---
int x = 5, y = 6, z = 50;
System.out.println(x + y + z);  // Output: 61

Note: Both ways work. Declaring one per line makes code more readable, but declaring multiple in one line is more concise.


9. ASSIGNING SAME VALUE TO MULTIPLE VARIABLES
-----------------------------------------------------------------------------------------------------------------------------------------------------
You can assign the same value to multiple variables in one statement using multiple '=' operators.

Example:
---
int x, y, z;
x = y = z = 50;
System.out.println(x + y + z);  // Output: 150

How it works:
1. z gets 50
2. y gets the value of z (50)
3. x gets the value of y (50)
4. All three variables now hold 50


PART 5: IDENTIFIERS (VARIABLE NAMING RULES)
======================================================================================================================================================

10. WHAT ARE IDENTIFIERS?
-----------------------------------------------------------------------------------------------------------------------------------------------------
Identifiers are unique names given to variables, methods, classes, and other elements in Java.

Examples of GOOD identifiers:
✅ age
✅ studentName
✅ minutesPerHour
✅ total_score
✅ MAX_USERS

Examples of BAD identifiers:
❌ 2ndNumber (starts with digit)
❌ my var (contains space)
❌ int (reserved keyword)


11. NAMING RULES FOR IDENTIFIERS
-----------------------------------------------------------------------------------------------------------------------------------------------------
Follow these rules when naming variables:

✓ ALLOWED:
  - Letters (A-Z, a-z)
  - Digits (0-9) - but NOT as first character
  - Underscores (_)
  - Dollar signs ($)

✓ MUST START WITH:
  - A letter (a-z, A-Z)
  - Dollar sign ($)
  - Underscore (_)
  - NOT a digit

✓ CANNOT CONTAIN:
  - Whitespace (spaces)
  - Special characters (except $ and _)

✓ CASE-SENSITIVE:
  - "myVar" and "myvar" are DIFFERENT variables

✓ CANNOT USE:
  - Reserved keywords (int, boolean, final, class, etc.)


12. NAMING CONVENTIONS (Best Practices)
-----------------------------------------------------------------------------------------------------------------------------------------------------
Java follows specific conventions for better readability:

📌 Regular Variables (camelCase):
  Start with lowercase, capitalize each new word
  ✅ int age = 25;
  ✅ String firstName = "John";
  ✅ float averageScore = 85.5f;

📌 Constants (UPPER_CASE):
  All uppercase with underscores between words
  ✅ final int MAX_USERS = 100;
  ✅ final String COUNTRY = "Bangladesh";

📌 Descriptive Names:
  Use clear, meaningful names that describe purpose
  ✅ int minutesPerHour = 60;  // Good, clear meaning
  ❌ int m = 60;               // Bad, unclear


13. EXAMPLES OF VALID AND INVALID IDENTIFIERS
-----------------------------------------------------------------------------------------------------------------------------------------------------

VALID (Will compile):
✅ int age = 25;
✅ String _name = "John";
✅ int $price = 100;
✅ float score2 = 95.5f;
✅ boolean isActive = true;

INVALID (Will cause errors):
❌ int 2ndNumber = 5;        // Error: Cannot start with digit
❌ int my var = 10;          // Error: Cannot contain space
❌ int int = 20;             // Error: 'int' is reserved keyword
❌ String my-name = "John";  // Error: Cannot contain hyphen
❌ float #price = 50.5f;     // Error: Cannot contain # symbol


PART 6: CONSTANTS WITH final KEYWORD
======================================================================================================================================================

14. CONCEPT: CONSTANTS WITH final KEYWORD
-----------------------------------------------------------------------------------------------------------------------------------------------------
When you do not want a variable's value to change, use the 'final' keyword.
A variable declared with 'final' becomes a constant - unchangeable and read-only.


15. SYNTAX FOR CONSTANTS
-----------------------------------------------------------------------------------------------------------------------------------------------------
final dataType CONSTANT_NAME = value;

Example:
final int myNum = 15;
final int MINUTES_PER_HOUR = 60;
final String COUNTRY = "Bangladesh";


16. WHAT HAPPENS IF YOU TRY TO CHANGE A final VARIABLE?
-----------------------------------------------------------------------------------------------------------------------------------------------------
❌ Error Example:
final int myNum = 15;
myNum = 20;  // Compilation Error: cannot assign a value to final variable 'myNum'

✅ Correct Usage:
final int myNum = 15;
System.out.println(myNum);  // Output: 15
// myNum cannot be reassigned


17. WHEN TO USE final?
-----------------------------------------------------------------------------------------------------------------------------------------------------
Use 'final' for values that should NEVER change, such as:
- Mathematical constants (PI = 3.14159)
- Time units (MINUTES_PER_HOUR = 60, SECONDS_PER_MINUTE = 60)
- Personal data (BIRTHYEAR = 1980)
- Configuration values that stay constant
- System constants


18. NAMING CONVENTION FOR CONSTANTS
-----------------------------------------------------------------------------------------------------------------------------------------------------
📌 By convention, final variables in Java are written in UPPER CASE.

Examples:
✅ CORRECT:  final int MINUTES_PER_HOUR = 60;
✅ CORRECT:  final String COUNTRY = "Bangladesh";
❌ NOT RECOMMENDED: final int minutesPerHour = 60;

Why Upper Case?
- Improves code readability
- Makes it clear that the variable is a constant
- Common practice among Java programmers worldwide


19. COMPLETE CODE EXAMPLES
-----------------------------------------------------------------------------------------------------------------------------------------------------

Example 1: Circle Area Calculator with Constants
---
final double PI = 3.14159;
double radius = 5;
double area = PI * radius * radius;
System.out.println("Area: " + area);  // Output: Area: 78.53975


Example 2: Time Conversion with Multiple Constants
---
final int MINUTES_PER_HOUR = 60;
final int SECONDS_PER_MINUTE = 60;
final int HOURS_PER_DAY = 24;

int totalSeconds = HOURS_PER_DAY * MINUTES_PER_HOUR * SECONDS_PER_MINUTE;
System.out.println("Total seconds in a day: " + totalSeconds);
// Output: Total seconds in a day: 86400


Example 3: Personal Information using Constants
---
final int BIRTHYEAR = 1980;
final String FULLNAME = "Sourov Chandra Das";
final String UNIVERSITY = "BUBT";

System.out.println("Name: " + FULLNAME);
System.out.println("Birth Year: " + BIRTHYEAR);
System.out.println("University: " + UNIVERSITY);


Example 4: Real-World Application
---
public class StudentRecord {
    // Constants for this application
    final String UNIVERSITY_NAME = "BUBT";
    final int CURRENT_YEAR = 2024;
    final double GPA_SCALE = 4.0;
    final int MAX_CREDITS_PER_SEMESTER = 18;
    
    public static void main(String[] args) {
        StudentRecord record = new StudentRecord();
        
        System.out.println("University: " + record.UNIVERSITY_NAME);
        System.out.println("Current Year: " + record.CURRENT_YEAR);
        System.out.println("GPA Scale: " + record.GPA_SCALE);
        System.out.println("Max Credits: " + record.MAX_CREDITS_PER_SEMESTER);
        
        // This would cause an error:
        // record.UNIVERSITY_NAME = "DU";  // ❌ Error!
    }
}


PART 7: COMMON MISTAKES & BEST PRACTICES
======================================================================================================================================================

20. COMMON MISTAKES
-----------------------------------------------------------------------------------------------------------------------------------------------------

❌ Mistake 1: Trying to reassign a final variable
final int MAX_USERS = 100;
MAX_USERS = 150;  // Compilation Error!

❌ Mistake 2: Not using upper case for constants (works but bad practice)
final int maxUsers = 100;  // Works, but not recommended

❌ Mistake 3: Forgetting to initialize final variable
final int MAX_USERS;  // Compilation Error!
// final variables MUST be initialized when declared

❌ Mistake 4: Concatenating numbers without parentheses
int x = 5, y = 6;
System.out.println("Sum: " + x + y);  // Prints "Sum: 56" NOT "Sum: 11"

❌ Mistake 5: Using reserved keywords as variable names
int int = 5;        // Error!
String class = ""; // Error!

❌ Mistake 6: Variable names with spaces
int my var = 10;  // Error!
int my-var = 10;  // Error!

❌ Mistake 7: Starting variable name with digit
int 2ndNumber = 5;  // Error!

✅ Correct Practices:
final int MAX_USERS = 100;           // Correct
int myNum = 15;                       // Correct
float price = 19.99f;                 // Correct
System.out.println("Sum: " + (x + y)); // Correct

PART 9: PRACTICE QUESTIONS
======================================================================================================================================================

22. PRACTICE QUESTIONS WITH ANSWERS
-----------------------------------------------------------------------------------------------------------------------------------------------------

Q1: What is a variable in Java?
A: A variable is a container for storing data values. It has a name, a type, and a value.

Q2: What data types are available in Java?
A: String, int, float, char, boolean (and others). String stores text, int stores whole numbers, 
float stores decimals, char stores single characters, boolean stores true/false.

Q3: How do you declare a variable in Java?
A: Use the syntax: type variableName = value;
Example: int age = 25;

Q4: Can you declare a variable without assigning a value?
A: Yes, but you must assign a value before using it.
Example: int x; x = 10; (valid) OR int x; System.out.println(x); (error)

Q5: What happens when you reassign a variable?
A: The new value overwrites the previous value.

Q6: What is the difference between String concatenation and numeric addition?
A: '+' with Strings joins them together. '+' with numbers adds them mathematically.

Q7: What is wrong with this code?
int x = 5, y = 6;
System.out.println("Sum: " + x + y);
A: It prints "Sum: 56" instead of "Sum: 11" because without parentheses, numbers are treated as text.
Fix: System.out.println("Sum: " + (x + y));

Q8: What naming convention should you use for regular variables?
A: camelCase - start with lowercase, capitalize first letter of each new word.
Example: int firstName = "John";

Q9: What naming convention should you use for constants?
A: UPPER_CASE - all uppercase with underscores between words.
Example: final int MAX_USERS = 100;

Q10: Can you start a variable name with a digit?
A: No, variable names must start with a letter, underscore (_), or dollar sign ($).

Q11: What does the 'final' keyword do?
A: It makes a variable a constant - unchangeable and read-only.

Q12: Can you declare a final variable without initializing it?
A: No, final variables must be initialized when declared.

Q13: What is the naming convention for final variables?
A: UPPER_CASE (all uppercase). It's not required but recommended for readability.

Q14: Which of these is a valid identifier?
a) int 2ndNumber = 5;
b) int _age = 25;
c) int my var = 10;
d) int int = 5;
A: Only (b) is valid. (a) starts with digit, (c) has space, (d) uses reserved keyword.

Q15: What will this code print?
String firstName = "John";
String lastName = "Doe";
System.out.println(firstName + " " + lastName);
A: John Doe
